This is a [Vite](https://vitejs.dev) project bootstrapped with [`create-wagmi`](https://github.com/wevm/wagmi/tree/main/packages/create-wagmi).



It is recommended that you use the latest LTS version of Node. Once both are installed, you can start preparing your project.

Run the following command to generate the project inside the solidity-refresh-todo directory
npm create wagmi@latest todos-frontend


Head to the todos-frontend and run the following command.
npm install --save-dev @wagmi/cli


Generate the wagmi config, simply run the following command.
npx wagmi init


Run the following command to generate the custom React hooks.
npx wagmi generate


Run the command to test out that your project is working.
npm run dev
